# MineRescue Rover Website

Front-end-only demonstration website for the AI-Powered Intelligent Mine Rescue Support Rover (SIH PS 26039).

## Files
- `index.html` — page structure and content
- `style.css` — responsive dark control-room / industrial UI
- `script.js` — simulated telemetry, mission timer and demo interactions

## Run
No backend, database, Node.js or build step is required.

Just open `index.html` in a browser.

## Important
All dashboard readings are simulated demo values. The site does not claim to receive real rover data.

When the real rover is ready, the simulated values in `script.js` can be replaced with data from your API/WebSocket/serial gateway.
